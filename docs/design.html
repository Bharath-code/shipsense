Do's and Don'ts

  • ✓ Use mono tabular numerals for every comparable metric.
  • ✓ Exactly one primary button per screen.
  • ✓ success = up, danger = down, muted = flat — always.
  • ✓ Borders + surface steps for card elevation.
  • ✓ Let whitespace separate sections.
  • ✗ Default shadcn gray neutrals.
  • ✗ Mixing rounded-none and rounded components in one view.
  • ✗ Primary violet used decoratively.
  • ✗ A second accent color competing with cyan.
  • ✗ Gamification chrome outranking the score itself.
