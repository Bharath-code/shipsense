# ShipSense Strategic Roadmap: Agentic Pivot

This roadmap transforms ShipSense from a repository health dashboard into an **AI-powered Co-founder** for open-source maintainers.

## 🎯 Strategic Goal
Shift the value proposition from **Passive Monitoring** $\rightarrow$ **Active Intelligence**.

---

## 🛠️ Task Breakdown

### Phase 1: Competitive Intelligence (FOMO)
*Goal: Drive engagement by allowing users to track competitors.*

- [ ] **T1.1: Watchlist Schema & Mutations**
  - Implement Convex mutations to add/remove public repos from a user's watchlist.
- [ ] **T1.2: Watchlist Data Sync**
  - Build background jobs to fetch and cache daily metrics for watched repos.
- [ ] **T1.3: Competitor Comparison UI**
  - Create a comparison view showing the user's repo vs. watched repos (Growth, Stars, Activity).

### Phase 2: Growth & Lead Generation
*Goal: Build a nurture sequence for non-authenticated users.*

- [ ] **T2.1: Landing Page Lead Form**
  - Add a "Check my repo health" email capture form to the landing page.
- [ ] **T2.2: Lead Storage Backend**
  - Implement Convex logic to store leads and trigger initial report generation.

### Phase 3: The Agent Layer (The "Wow" Moment)
*Goal: Transition from insights to actions.*

- [ ] **T3.1: GitHub Write Permissions**
  - Update OAuth scopes to allow writing issues/comments.
- [ ] **T3.2: AI Reply Drafts Backend**
  - Implement Gemini-powered drafting for GitHub issues.
- [ ] **T3.3: One-Click Action UI**
  - Build an "Action Center" in the dashboard for one-click replies and merges.

### Phase 4: Revenue & High-Value Assets
*Goal: Create "must-have" assets for founders.*

- [ ] **T4.1: Investor Report Template**
  - Design a high-fidelity PDF template for repository traction.
- [ ] **T4.2: PDF Generation Engine**
  - Implement the backend logic to generate and deliver these reports.

### Phase 5: Polish & Brand
*Goal: Ensure the product feels "World Class".*

- [ ] **T5.1: Animation Polish**
  - Audit and refine all transitions and micro-interactions for an elegant, non-jarring feel.

---
